# Security Policy — Contador de Sementes

## Reporting a Vulnerability

If you discover a security vulnerability, report it privately to the maintainers.

## Security Guidelines

- Do not commit secrets or `.env` files.
- Keep optional AI or external-service credentials restricted by domain and usage.
- Review dependencies regularly with `npm audit`.
- Keep Docker images free of embedded secrets.
